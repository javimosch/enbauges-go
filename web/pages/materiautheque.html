Où et comment

Le registre est une chaîne de blocs : chaque inscription est signée, chaque bloc contient l'empreinte du précédent. Une copie vit sur le serveur d'enbauges.fr (qui signe les inscriptions) et une autre sur une machine indépendante. Modifier une ligne après coup casserait la chaîne sur toutes les copies : c'est ce qui rend l'historique fiable sans avoir à faire confiance au site.

Se tromper, c'est possible ; effacer, non

Une erreur ne se corrige pas en réécrivant le passé mais en ajoutant une inscription « correction » qui pointe vers l'originale. Les deux restent visibles. Le logiciel du registre, greffe, est libre ; celui de cette page aussi.

Le bouton demande au registre de tout revérifier depuis le premier bloc : chaque empreinte, chaque signature, chaque règle d'écriture. Le résultat vient du registre, pas de ce site.
