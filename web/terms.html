Conditions d'utilisation

Dernière mise à jour : septembre 2026

1. Objet

La Commune des Bauges (enbauges.fr) est une plateforme territoriale qui agrège des informations publiques sur le Cœur des Bauges (Massif des Bauges, Savoie). Les présentes conditions définissent les modalités d'accès et d'utilisation des données disponibles sur le site.

2. Provenance des données

Les données présentées sur le site sont collectées depuis des sources publiques : sites web des communes, Radio Alto (105.5 FM), OpenStreetMap, et contributions directes. La Commune des Bauges n'est pas propriétaire de ces données. Elle les agrège et les présente pour faciliter la découverte du territoire.

3. Consultation

La consultation du site (canvas, agenda, annuaire) est libre et gratuite. L'abonnement à l'agenda via le flux iCal est également libre.

4. Exports en masse

L'accès aux exports machine-readable (JSON, CSV, GeoJSON) nécessite une clé API, délivrée sur demande. L'obtention d'une clé implique l'acceptation des présentes conditions.

5. Redistribution

La redistribution des données extraites — publication sur un autre site, mise à disposition via une API tierce, inclusion dans un service commercial — est interdite sans autorisation expresse. Les droits de réutilisation relèvent des sources d'origine (communes, Radio Alto, contributeurs OpenStreetMap).

6. Mention de source

Toute utilisation des données doit mentionner « La Commune des Bauges — enbauges.fr » comme source de l'agrégation, ainsi que les sources d'origine lorsque celles-ci sont identifiées.

7. Données personnelles

Certaines données (noms d'organisateurs, contacts) peuvent constituer des données personnelles au sens du RGPD. Elles ne sont pas incluses dans les exports en masse. Pour toute demande relative aux données personnelles, voir notre politique de confidentialité.

8. Limitation de responsabilité

Les données sont fournies « telles quelles », sans garantie d'exhaustivité, d'exactitude ou de mise à jour. La Commune des Bauges ne saurait être tenue responsable des décisions prises sur la base de ces données.

9. Contact

Pour toute question relative à l'utilisation des données ou pour demander une clé API : contact@savoietech.fr
