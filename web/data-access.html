Accès aux données

La Commune des Bauges collecte des informations depuis des sources publiques (sites web des communes, Radio Alto, OpenStreetMap) pour constituer une carte vivante du territoire. Les données sont consultables librement sur le site. L'accès aux exports en masse (JSON, CSV, GeoJSON) est contrôlé et nécessite une clé API.

Accessible librement

  • Le canvas — cartes du territoire (acteurs, solutions, initiatives)
  • L'agenda — événements publics du Cœur des Bauges
  • L'annuaire — liste imprimable des acteurs
  • L'agenda en iCal — abonnement calendrier (Thunderbird, Google Agenda, iPhone)

Exports en masse — clé API requise

Pour accéder aux exports machine-readable (JSON, CSV, GeoJSON), une clé API est nécessaire. Cela nous permet de contrôler la redistribution et d'assurer le respect des sources.

  • /api/export/cards.json?key=... — cartes + liens
  • /api/export/cards.csv?key=... — cartes en tableur
  • /api/export/cards.geojson?key=... — cartes géolocalisées
  • /api/export/events.json?key=... — événements

Pour demander une clé : contact@savoietech.fr

Provenance des données

Les données présentées sur La Commune des Bauges proviennent de sources publiques :

Sites web des communes Événements, informations pratiques
Radio Alto (105.5 FM) Annonces d'événements (transcriptions)
OpenStreetMap Géolocalisation, lieux référencés
Contributions directes Cartes ajoutées par les acteurs du territoire

La Commune des Bauges ne prétend pas être propriétaire de ces données. Elle les agrège et les présente pour faciliter la découverte du territoire. Les droits de réutilisation relèvent des sources d'origine.

Conditions d'utilisation

  • La consultation du site est libre et gratuite
  • Les exports en masse sont destinés à un usage personnel ou de recherche
  • La redistribution des données extraites (publication, API tierce, service commercial) est interdite sans autorisation
  • Toute utilisation doit mentionner la source (« La Commune des Bauges — enbauges.fr ») et les sources d'origine
  • Les données sont fournies « telles quelles », sans garantie d'exhaustivité ou d'exactitude
